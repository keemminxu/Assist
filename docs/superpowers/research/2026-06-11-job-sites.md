# 채용 사이트 수집 가능성 스파이크 결과 (2026-06-11)

키워드: "언리얼" / "Unreal". 각 사이트를 직접 fetch → 실패 시 검색 경유 순으로 검증.

## 판정 요약

| 사이트 | 판정 | job-scan에서 사용할 방법 |
|---|---|---|
| 원티드 | ✅ 직접 (공개 JSON API) | `GET https://www.wanted.co.kr/api/v4/jobs?query=언리얼&country=kr&job_sort=job.latest_order&limit=20` → JSON에서 회사명·포지션·id 추출, 상세 URL은 `https://www.wanted.co.kr/wd/{id}` |
| 잡코리아 | ✅ 직접 (서버 렌더링 HTML) | `GET https://www.jobkorea.co.kr/Search/?stext=언리얼` → 목록에서 회사명·포지션·링크 파싱 (검증 시 243건 정상 표시) |
| 사람인 | 🔁 검색 경유 | PC·모바일 모두 JS 동적 로딩이라 직접 fetch 불가. WebSearch `site:saramin.co.kr 언리얼 채용` 으로 수집 (jumpit.saramin.co.kr 포지션 포함, 검증 시 공고 다수 확인) |
| 게임잡 | ⚠️ 부분 (목록 필터링) | 키워드 GET 파라미터 미지원(404 또는 무시), site: 검색은 커뮤니티 글 위주라 부적합. 대신 `https://www.gamejob.co.kr/recruit/joblist` 전체 목록이 서버 렌더링되므로 **목록을 fetch해 제목에 언리얼/Unreal 포함된 것만 필터링**. 제목에 키워드 없는 공고는 누락될 수 있음 — 보고에 한계 명시 |

## 상세 검증 기록

- **원티드 API**: 200 OK, JSON 정상. 표본: 어메이즈VR(언리얼 VR 3D 그래픽 디자이너, id 361418), 소울웍스(언리얼기반 3D 비주얼 아티스트, id 355014), 비전스페이스(언리얼 개발자 3년 이상, id 353726)
- **잡코리아**: 200 OK, 목록 파싱 가능. 표본: 아폴로스튜디오코리아(언리얼5 TA), 플럭시티(3D 클라이언트 개발자), 여성기업종합지원센터
- **사람인 PC** (`zf_user/search?searchword=언리얼`): "총 181건" 카운트만 렌더링, 목록은 "잠시만 기다려주세요" 로딩 상태 — JS 필요
- **사람인 모바일** (`m.saramin.co.kr/search`): 동일하게 동적 로딩 — 직접 불가
- **사람인 검색 경유**: `site:saramin.co.kr 언리얼 채용` → 본채용·점핏 공고 10건 안정적으로 반환 ✅
- **게임잡** (`List_GI/GIB_Search.asp?Keyword=언리얼`): 404. (`recruit/joblist?menucode=search&searchtext=언리얼`): 키워드 무시되고 전체 목록 표시(서버 렌더링은 됨). `site:gamejob.co.kr 언리얼`: 커뮤니티 글만 잡힘

## job-scan 루틴에 반영할 결론

1. 수집 순서: 원티드 API → 잡코리아 HTML → 사람인 검색 경유 → 게임잡 목록 필터
2. 게임잡은 "제목 키워드 필터" 방식의 한계(누락 가능)를 보고 말미에 명시
3. 어떤 사이트든 그날 실패하면 "N/4 사이트 확인"으로 투명하게 보고 (침묵 금지)
